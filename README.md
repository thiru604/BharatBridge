# 🇮🇳 BharatBridge

A bidirectional voice and text translation system for 
Indian workers — converting manager messages into native 
languages and replies back to English.

## Problem It Solves
400 million Indian workers communicate in regional 
languages but work in English environments. 
BharatBridge bridges this gap.

## Features
- ✅ English → Native language translation
- ✅ Native language → English translation
- ✅ Supports 10 Indian languages
- ✅ Simple web interface via Streamlit
- 🔄 Voice input — coming soon
- 🔄 WhatsApp integration — coming soon

## Supported Languages
Hindi, Tamil, Telugu, Bengali, Marathi,
Kannada, Malayalam, Punjabi, Gujarati, Urdu

## Tech Stack
- Python 3.11
- Streamlit (UI)
- deep-translator (Translation engine)
- OpenAI Whisper (Voice — V2)
- Twilio (WhatsApp — V3)

## How to Run
git clone https://github.com/thiru604/BharatBridge.git
cd BharatBridge
pip install -r requirements.txt
streamlit run app.py
